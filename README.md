# チャイ レジ

一橋祭の模擬店用レジ。GitHub Pages で公開し、売上は Google スプレッドシートに保存します。

- メニューをタップ → 「記録する」で販売杯数を記録（お預かり・お釣りの入力なし）
- 現金のみ。ホットチャイ400円・知り合い割200円・4杯セット1000円（杯数も集計）
- 会計の取消
- 複数端末（レジ1・レジ2…）で同じスプレッドシートに記録
- 電波が切れても端末に保存し、つながったら自動送信（ヘッダーに「未送信 n件」と表示）
- 集計：売上合計・商品別・時間帯別・レジ別、CSV書き出し

## 1. スプレッドシート側の準備

1. Google ドライブで新しいスプレッドシートを作る（例：「一橋祭 チャイ 売上」）
2. メニューの **拡張機能 → Apps Script** を開く
3. `コード.gs` の中身を全部消して、このリポジトリの [`gas/Code.gs`](gas/Code.gs) を貼り付ける
4. 先頭の `const TOKEN = '...'` を**サイトのログイン合言葉と同じもの**に書き換えて保存（合言葉はメンバーに直接伝える。READMEやGitHubには書かない）
5. 左の「プロジェクトの設定（歯車）」でタイムゾーンを **(GMT+09:00) 東京** にする
6. 関数 `setup` を選んで「実行」→ 権限を承認（「売上」「売上明細」「メニュー」シートができる）
7. 右上 **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
8. 表示された **ウェブアプリURL**（`https://script.google.com/macros/s/.../exec`）をコピー

> Code.gs を書き換えたら「デプロイを管理 → 編集 → バージョン：新バージョン」で再デプロイが必要です。

## 2. GitHub Pages で公開

1. GitHub で新しいリポジトリを作る（例：`chai-pos`）
2. このフォルダの中身（`index.html` `style.css` `app.js` `gas/` `README.md`）をアップロード
3. リポジトリの **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/chai-pos/` で開けるようになる

## 3. 各レジ端末の設定

サイトを開くとログイン画面が出るので合言葉を入力。ログイン後、**設定** タブで

- Apps Script ウェブアプリURL
- レジ名（端末ごとに「レジ1」「レジ2」など別の名前に）

を入れて「保存」。メニューの商品名・価格・杯数・色もここで編集でき、全端末に共有されます。

URL 未設定のままでも「ローカルモード」で使えます（あとで URL を設定すると、それまでの売上もまとめて送信）。

## 注意

- 合言葉は簡易的な保護です。サイトURL・API URL・合言葉を部外者に広めないでください。
- 合言葉を変えるときは、`app.js` の `PASS_HASH`（合言葉の SHA-256）と Code.gs の `TOKEN` の両方を変更します。
- スプレッドシートを直接編集する場合、「売上」シートの ID 列と 明細JSON 列は変更しないでください。
- 売上データは各端末のブラウザにも残ります。祭り終了後に不要なら、ブラウザのサイトデータを削除してください。
